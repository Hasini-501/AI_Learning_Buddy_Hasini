# 🎓 AI Learning Buddy Hasini

AI Learning Buddy Hasini is an interactive educational web application built using Python, Streamlit, and Google's Gemini API.

## Features
- 📖 Explain concepts in simple language
- 💡 Generate real-life examples
- 📝 Generate quizzes
- 🤖 AI-powered tutoring
- 🎯 Interactive learning experience

## Technologies Used
- Python
- Streamlit
- Google Gemini API

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
